# zopra

Runtime reativo pequeno, em JavaScript: `signal`, `computed`, `effect`, um `h()` mínimo e um canvas WebGL que lê o mesmo sinal que o texto.

Não é Rust e não fala com GPU nativa. O uniforme do fragment shader é a parte de GPU — o bastante para ver a ideia sem uma toolchain.

## Exemplo

```bash
python -m http.server
```

Abra `examples/index.html` pelo servidor.
